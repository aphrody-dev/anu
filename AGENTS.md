# AGENTS.md

Contract for every agent working in ANU (Aphrody's Not Unix). Identity and sources come from `anu.toml`.

## Scope
- One monorepo of the Unix, GNU, Linux and NT world in Rust, C and assembly: unixwin, uutils, Rust for Linux and
  Rust kernels, Microsoft Rust, Rust GNU replacements, rust-lang, Linux From Scratch, GNU/Linux, POSIX, NT and Win32
  docs and specs, skills, and the software index matrix (`index/`).
- ANU depends on no other Aphrody repository.

## Rules
- Upstreams are git submodules with relative URLs to aphrody-labs forks, one checkout each; never copies.
- `index/*.toml` is generated by `tools/*.ts`; edit the generator, not the output. Versions and counts are read live.
- Specs that cannot be redistributed are indexed by URL in `docs/specs.toml`, not mirrored.
- Heavy clones and builds run on the build host (`ssh fr1`, `/srv/xbuild/anu`), not the PC.
- Work on `main`; commit by path; no branches, worktrees, stash or reset; no AI attribution.
- Run `bun test tools` before every push.
